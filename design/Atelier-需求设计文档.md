# Atelier 需求设计文档

版本：1.0  
日期：2026-07-27  
状态：设计确认稿  
本轮范围：需求设计与全部页面 UI 预览

---

## 1. 产品定义

Atelier 是一个基于 FastAPI 与前后端分离架构的 ComfyUI 项目化视觉生产工作台。它以两类画布为核心：

1. **剧本积木画布**：手动拼接章节、大场景、小场景、转场、分镜页和版本分支，生成以页为单位的跑图列表。
2. **ComfyUI 工作流画布**：完整编辑 ComfyUI 节点、端口、连线、组件参数及已安装的自定义节点，并通过自动布局保持节点规整。

Atelier 不负责自动创作剧情。用户自行管理和拼接素材，系统负责结构化、版本化、批量执行、产出管理与最终装配。

### 1.1 核心价值

- 将零散素材组合为可执行、可追踪的项目结构。
- 用新的高效率 UI 替代 ComfyUI 原生节点编辑体验。
- 在不写死工作流的前提下，实现项目级人物批量替换。
- 让每个分镜页拥有多次生成、多张候选、多张采用结果。
- 在百万级图片规模下保持图库滚动、筛选和预览流畅。
- 将前端和 FastAPI 后端合并到一个访问端口，降低本地部署复杂度。

### 1.2 非目标

- 本阶段不接入 AI 自动生成剧情、分镜或提示词。
- 本阶段不复刻现有五步 Markdown 工作流。
- 本阶段不设计旧目录导入与迁移策略。
- 第一版不安装、更新或卸载远端 ComfyUI 自定义节点，只显示并使用 ComfyUI 已安装节点。
- 不替代 ComfyUI 的模型和自定义节点运行环境。

| 项目 | 约束 |
|---|---|
| 用户形态 | Windows 单机单用户，允许局域网访问 |
| 登录 | 第一版无登录 |
| 后端 | Python FastAPI |
| 前端 | React + TypeScript |

| 文件系统 | 原图与缩略图保存在可配置的数据目录 |
| UI | 第一版明亮苹果风，后续支持多彩主题 |

├─ 剧本版本
│  ├─ 章节
│  │  ├─ 大场景
│  │  │  ├─ 小场景
│  │  │  │  ├─ 转场
│  │  │  │  └─ 分镜页
│  │  │  └─ 条件分支
│  │  └─ 条件分支
│  └─ 启用的分支组合
├─ 工作流
│  ├─ ComfyUI 节点图
│  └─ 语义插槽绑定

| MaterialPack | 单页镜头模板、场景包、转场包 |

| CharacterVariant | 服装或形象版本 |
| CharacterSpec | 景别规格或自定义规格 |
| Workflow | ComfyUI UI/API JSON 及版本 |

| FinalSequence | 最终作品的扁平排序 |

## 4. 双画布设计

## 4.1 剧本积木画布

### 4.1.1 目标

让用户不用编辑 Markdown 或表格，通过拖拽结构块与素材包完成剧本装配，并编译为以页为单位的跑图列表。

### 4.1.2 画布层级

| 层级 | 行为 |
|---|---|
| 章节 | 顶层容器，可折叠、排序、复制 |
| 大场景 | 章节内主叙事段，可创建条件分支 |
| 小场景 | 大场景内局部空间或连续动作段，可创建条件分支 |
| 转场 | 连接两个场景的特殊结构块 |
| 分镜页 | 最小执行单位，生成跑图列表的一行 |
| 分支 | 从大场景或小场景处分叉，具有独立覆盖项 |

### 4.1.3 编辑方式

- 左侧素材抽屉拖入画布。
- 横向主线展示章节和场景的先后关系。
- 场景内部展开为纵向分镜页列表。
- 拖入“单页镜头模板”时新增一页。
- 拖入“场景包”时展开为多张有序分镜页。
- 分支从大场景或小场景连接点创建。
- 分支可单独启用、停用、生成或复制。
- 分支默认继承父级素材和角色设置，只保存差异覆盖。
- 所有启用分支可一键编译为多个跑图版本。
- 画布提供缩略导航、层级面包屑、折叠和聚焦模式。

### 4.1.4 分支用途

分支既可表达剧情差异，也可表达角色形象差异。例如同一段内容建立两个分支：

- 分支 A：裙装形象变体。
- 分支 B：短裤形象变体。

两个分支可同时启用，分别生成独立成品版本。分支覆盖范围包括：

- 人物形象变体。
- 分镜页顺序和数量。
- 分镜素材引用。
- 提示词片段。
- 工作流选择与语义插槽值。
- 生成参数。

### 4.1.5 编译为跑图列表

画布编译时执行：

1. 展开章节、大场景、小场景与场景包。
2. 计算所有启用分支组合。
3. 合并项目、章节、场景、分支和分镜页的继承配置。
4. 解析人物规格和形象变体。
5. 解析工作流语义插槽。
6. 为每张分镜页生成确定的运行项。
7. 输出校验结果和运行项总数。

编译只生成清单，不自动开始生成。用户在批量配置页确认后提交。

## 4.2 ComfyUI 工作流画布

### 4.2.1 兼容范围

- 导入和导出 ComfyUI UI JSON。
- 必要时转换并提交 API JSON。
- 从 `/object_info` 读取标准节点和已安装的自定义节点。
- 支持节点输入组件、输入端口、输出端口、连线、节点组、旁路和禁用。
- 支持图片中提取工作流元数据。
- 保存工作流版本和项目副本。

### 4.2.2 自动布局

节点不允许自由拖动。系统根据拓扑自动放置：

- 默认从左到右按执行层级分列。
- 同一层级按依赖和节点类型自动排序。
- 连线交叉数作为布局优化指标。
- 节点宽度根据组件类型自动选择有限档位。
- 组节点形成固定泳道。
- 新增节点后自动插入合适层级并平滑重排。
- 用户可对节点执行“前移、后移、换列、置顶、置底”，但不能任意改变坐标。
- 支持从上到下布局作为替代视图。
- 支持折叠普通参数，仅保留重要端口。
- 支持聚焦某节点及其上下游路径。

### 4.2.3 连线

- 用户从输出端口拖到兼容输入端口。
- 不兼容端口不可放置，并显示类型原因。
- 连线自动选择路径，避开节点卡片。
- 同类型多条连线自动合束。
- 选中连线显示数据类型、来源和目标。
- 删除节点前展示受影响的下游节点。

### 4.2.4 新节点 UI

节点采用圆润卡片而非原生 ComfyUI 面板：

- 顶部为节点类型、状态和折叠按钮。
- 左侧输入端口，右侧输出端口。
- 核心参数直接展示，次要参数折叠。
- 模型、LoRA 和枚举字段使用可搜索选择器。
- 数值字段同时支持滑杆、步进和精确输入。
- 长提示词使用可展开文本编辑区。
- 节点颜色只表达类别，不大面积填充。
- 错误、缺失模型和无效连接直接定位到字段。

### 4.2.5 语义插槽

用户可将任意节点输入标记为业务语义插槽：

| 插槽示例 | 可绑定目标 |
|---|---|
| 正向提示词 | 文本编码节点的文本输入 |
| 负向提示词 | 文本编码节点的文本输入 |
| 角色提示词 | 任意文本输入 |
| 角色 LoRA | LoRA 加载节点的模型名输入 |
| LoRA 权重 | LoRA 加载节点的数值输入 |
| 基础模型 | 模型加载节点的名称输入 |
| 种子 | 采样节点的 seed 输入 |
| 宽度 / 高度 | 图像尺寸节点输入 |
| 批次数量 | 批次或潜空间节点输入 |
| 输出前缀 | 保存图片节点输入 |

插槽属于工作流版本。批量运行时，Atelier 根据项目、分支、人物和分镜页计算插槽值，再注入实际节点。

## 5. 素材系统

## 5.1 画布结构块

章节、大场景、小场景、转场、分镜页和条件分支是画布结构，不作为普通素材混入素材库。

## 5.2 原子分镜素材

| 类型 | 内容 |
|---|---|
| 构图 | 景别、视角、人物位置、画面方向 |
| 姿态与互动 | 单一静态动作及人物相对位置 |
| 表情与视线 | 表情、视线方向、可见情绪 |
| 环境与道具 | 地点、背景、环境细节和关键物体 |
| 光线与时间 | 光源、方向、色温、明暗、时间 |
| 正向提示词 | 可复用正向提示词片段 |
| 负向提示词 | 可复用负向提示词片段 |
| 生成参数 | 尺寸、采样器、步数、CFG、种子策略等 |

每个素材具有：

- 名称、类型、标签、说明。
- 结构化参数与最终文本值。
- 预览图片。
- 适用范围。
- 验证状态。
- 版本历史。
- 被项目和页面引用的反向列表。

## 5.3 复合模板

| 模板 | 作用 |
|---|---|
| 单页镜头模板 | 拖入剧本画布后生成一个分镜页 |
| 场景包 | 拖入后展开为多张有序分镜页 |
| 转场包 | 连接两个场景的多页或单页序列 |
| 工作流模板 | 可复用的 ComfyUI 工作流及语义插槽 |

复合模板支持“链接引用”和“复制后独立”两种使用方式。

## 6. 人物与批量替换

## 6.1 人物结构

```text
项目角色
├─ 默认形象
├─ 形象变体
│  ├─ 裙装
│  └─ 短裤
└─ 规格
   ├─ 全身
   ├─ 半身
   ├─ 特写
   └─ 用户自定义规格
```

每个“变体 × 规格”可保存：

- 角色提示词。
- 可选 LoRA 名称。
- 可选 LoRA 权重。
- 可选基础模型覆盖。
- 预览图片。
- 备注和验证状态。

## 6.2 替换逻辑

- 分镜页声明所需人物角色和规格。
- 分支选择人物形象变体。
- 工作流声明需要注入的语义插槽。
- 编译时将人物值写入对应插槽。
- 不使用 LoRA 的人物可只填写提示词。
- 一个工作流可绑定多个角色插槽。
- 未绑定必要插槽时阻止提交并定位错误。

## 6.3 替换矩阵

人物替换矩阵以“角色 × 规格”为主视图，支持：

- 批量粘贴提示词。
- 设置默认 LoRA 和权重。
- 对单个规格覆盖。
- 选择预览图。
- 显示哪些分镜页正在引用。
- 执行生成前完整性检查。

## 7. 跑图与任务系统

## 7.1 跑图列表

每个运行项至少包含：

- 项目、剧本版本、分支路径。
- 章节、大场景、小场景、分镜页编号。
- 分镜页标题和静态描述。
- 最终正向、负向提示词。
- 人物与规格引用。
- 工作流版本。
- 完整语义插槽快照。
- 生成参数。
- 计划生成实例数。

## 7.2 批量配置

- 可全选项目、章节、场景、分支或单页。
- 每页可配置不同生成实例数。
- 支持固定种子、随机种子、递增种子。
- 支持跳过已达到采用数量的页面。
- 支持只重跑失败项。
- 提交前展示预计任务数和输出数。
- 任务支持暂停队列、继续、取消、重试和调整优先级。

## 7.3 ComfyUI 执行

参考通信流程：

1. `GET /system_stats` 检查健康状态。
2. `GET /object_info` 同步节点定义。
3. 将 UI 工作流转换为 API 工作流。
4. 注入语义插槽、种子和输出前缀。
5. `POST /prompt` 提交任务。
6. WebSocket `/ws` 接收节点和采样进度。
7. 以 `/history/{prompt_id}` 轮询兜底。
8. 从 `/view` 拉取产出。
9. 写入项目存储并建立图片索引。
10. 保存工作流、提示词、参数和来源快照。

### 7.3.1 可靠性

- WebSocket 与 history 轮询并行，先完成者生效。
- 单任务超时可配置。
- 网络断开不丢失已提交的 ComfyUI `prompt_id`。
- 应用重启后恢复排队任务，运行中任务进入“待核对”状态。
- 失败项记录节点错误、响应正文和工作流快照。
- 取消单任务时仅在确认当前 ComfyUI 任务归属后执行中断。

## 8. 图片实例、审片与最终装配

## 8.1 单页多实例

一张分镜页可执行多次，每次产生一张或多张图片实例。图片实例默认状态为“候选”。

用户可：

- 同时采用多张实例。
- 淘汰不需要的实例。
- 对采用实例进行页内排序。
- 标记主封面或代表图。
- 查看实例对应的工作流、提示词、种子和参数。
- 从任意实例复制参数并再次生成。

## 8.2 最终作品装配

最终作品是全部采用实例的扁平有序序列：

- 默认顺序为剧本画布页序 + 页内采用顺序。
- 允许跨原分镜页拖动排序。
- 始终保留来源分镜页和分支路径。
- 同一图片可被多个最终版本引用，但文件只保存一份。
- 可建立多个最终版本，例如裙装版、短裤版、发布版。
- 修改最终排序不影响剧本画布顺序。

## 8.3 导出

- 按最终顺序重新编号并复制或硬链接到导出目录。
- 可选择是否去除工作流元数据。
- 可导出 PNG、JPEG 或保留原格式。
- 可输出清单 JSON/CSV，包含来源页、提示词、种子和工作流版本。
- 支持导出预设，但不把平台目录写死到核心数据模型。

## 9. 百万级图库架构

现有参考项目通过遍历目录并即时检查图片元数据的方式列出图片，不能用于百万级规模。Atelier 必须采用索引优先架构。

## 9.1 存储原则

- 原图不通过列表接口直接扫描。
- 新图片落盘后立即写入数据库。
- 后台索引器只处理新增或变更文件。
- 图片采用内容哈希去重，逻辑引用与物理文件分离。
- 缩略图预生成，不在列表滚动时同步生成。

## 9.2 图片索引

图片表建议字段：

- `id`
- `content_hash`
- `storage_path`
- `width`、`height`、`format`、`size_bytes`
- `created_at`、`indexed_at`
- `project_id`、`shot_page_id`、`generation_id`
- `workflow_id`、`workflow_version`
- `prompt_text`、`negative_prompt`
- `seed`、`model`、`sampler`
- `status`
- `rating`、`flags`
- `phash`，用于近似图片检测

关键索引：

- `(project_id, created_at, id)`
- `(shot_page_id, status, sort_index)`
- `(status, created_at, id)`
- `(content_hash)`
- `(workflow_id, created_at)`
- FTS5 提示词全文索引

## 9.3 缩略图

- 生成 256px 和 640px 两档 WebP 缩略图。
- 列表只请求 256px；快速预览请求 640px；打开详情才请求原图。
- 使用内容哈希作为不可变缓存键。
- 响应设置长缓存和 ETag。
- 缩略图生成进入低优先级后台队列。
- 缩略图失败显示占位图，不阻塞图库。

## 9.4 查询与渲染

- 后端使用游标分页，不使用大偏移量分页。
- 默认每批 100 条，可配置。
- 前端使用二维虚拟网格，仅挂载可视区域及少量缓冲项。
- 使用 IntersectionObserver 懒加载。
- 离开视口的图片请求可取消。
- 筛选和排序在服务端执行。
- 选择大量图片时保存 ID 集合，不在 DOM 中保持全部卡片。

## 9.5 性能目标

| 场景 | 目标 |
|---|---|
| 百万条索引首次打开图库 | 1 秒内出现首屏骨架，2 秒内出现首批缩略图 |
| DOM 图片卡片数量 | 通常不超过 250 |
| 单次列表响应 | 100 条，压缩后建议小于 150 KB |
| 快速滚动 | 主线程长任务少于 50 ms |
| 原图请求 | 仅在详情页或用户明确打开时发生 |
| 缩略图内存 | 离屏主动释放，浏览器内存保持稳定 |

## 11. 视觉与交互规范

## 11.1 视觉方向

- 明亮苹果风：大留白、半透明层次、柔和阴影和圆角。
- 背景使用冷灰白，核心操作区域使用纯白。
- 主色为蓝紫渐变；分支使用珊瑚、青绿、琥珀等轻量点缀。
- 圆角：大容器 20–24px，卡片 14–18px，按钮 10–14px。
- 字体优先使用系统字体：SF Pro、Segoe UI、PingFang SC。
- 避免大面积深色、霓虹描边和过度玻璃效果。

## 11.2 交互原则

- 主导航保持稳定，项目内二级导航按任务顺序排列。
- 复杂配置使用右侧检查器，不频繁弹窗。
- 拖拽动作始终显示落点和结果数量。
- 批量操作先预览影响范围。
- 自动保存，顶部持续显示保存状态。
- 删除进入回收站或软删除，关键删除需要确认。
- 画布修改支持撤销、重做和版本快照。

## 13. 单端口部署与 BAT 约束

### 13.1 构建部署

- 前端开发使用独立 Vite 端口。
- 发布构建生成静态文件。
- FastAPI 挂载静态文件并处理 SPA fallback。
- 正式使用时浏览器只访问 `http://127.0.0.1:8110`。

### 13.2 启动脚本

BAT 文件及其控制台文本全部使用英文。

启动流程：

1. 根据脚本自身目录确定项目根目录。
2. 查找项目虚拟环境 Python，再查找可用系统 Python。
3. 验证依赖可导入。
4. 检查目标端口监听进程。
5. 通过命令行中的项目绝对路径、启动标识和端口共同判断是否为 Atelier 自身进程。
6. 如果是旧 Atelier 进程，终止进程树并等待端口释放。
7. 如果是其他程序占用，输出占用 PID 和程序名，停止启动，不杀进程。
8. 启动 FastAPI。
9. 轮询健康接口。
10. 健康后打开浏览器；失败时清理自身进程并返回错误码。

严禁只按 `uvicorn main:app` 判断进程归属，避免误杀其他项目。

## 14. 数据安全与恢复

- SQLite 开启 WAL、外键和定期 checkpoint。
- 关键画布保存采用事务。
- 画布版本使用增量快照与定期全量快照。
- 图片文件先写临时名，校验后原子改名。
- 数据库记录只引用已完成落盘的文件。
- 删除图片默认软删除，后台延迟清理。
- 导出不改变图片采用状态。
- 备份范围包含数据库、工作流、素材元数据和项目配置；原图可按策略选择是否包含。

## 15. 验收标准

### 15.1 剧本画布

- 可创建任意数量的章节、大场景、小场景和分镜页。
- 可从大场景和小场景创建分支。
- 分支可分别绑定人物形象变体并同时编译。
- 拖入场景包后正确展开多张分镜页。
- 编译结果能追溯至原画布块和分支。

### 15.2 工作流画布

- 可加载 ComfyUI 标准与已安装自定义节点。
- 可完整编辑节点输入、端口和连线。
- 节点不能自由拖动，新增或删除后自动保持规整布局。
- 可导入、保存、版本化并导出工作流。
- 可绑定人物提示词、角色 LoRA、权重等语义插槽。
- 编译后的 API 工作流可以提交至默认 ComfyUI。

### 15.3 批量生成

- 可按项目、分支、场景和单页选择生成范围。
- 每页可设置生成多个实例。
- 任务可取消、重试、跳过和恢复。
- 所有图片保存来源页、工作流版本、提示词和种子快照。

### 15.4 审片与成片

- 单页可采用多张图片并排序。
- 最终装配页可跨分镜页排序。
- 最终图片仍能追踪到来源页和生成任务。
- 可创建和导出多个最终版本。

### 15.5 百万级图库

- 列表接口不扫描完整目录。
- 使用游标分页和虚拟网格。
- 首屏仅加载缩略图。
- 快速滚动不会持续增长 DOM 和图片内存。
- 任意筛选条件都在服务端执行并使用可验证索引。
