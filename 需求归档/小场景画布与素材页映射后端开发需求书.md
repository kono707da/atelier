## 1. 开发目标

为现有剧本画布补齐以下后端能力：

1. 在大场景下管理小场景。
2. 在小场景下管理场景页：新增、修改、删除、排序。
3. 在素材下管理只读展示用的素材页。
4. 将素材关联到小场景。
5. 将某个素材页映射到一个或多个场景页。
6. 提供项目剧本树和小场景工作区聚合接口，避免前端 N+1 请求。

本期不开发提示词、人物、LoRA、ComfyUI 工作流或 AI 自动编排。

## 2. 已确认业务规则

- 项目层级固定为：项目 → 章节 → 大场景 → 小场景。
- 小场景包含任意数量的场景页。
- 场景页首版只有：
  - 页面名称
  - 画面描述
  - 排序
  - 素材页映射
- 素材页属于素材库中的某一个素材，在小场景画布内只读，不允许编辑。
- 同一个素材页可以同时映射到多个场景页。
- 同一个场景页可以同时绑定不同类型的素材页，例如场景、表情、光线各一页。
- 同一个场景页在同一种素材类型下最多只能绑定一个素材页。
- 新绑定同类型素材页时，必须原子替换旧绑定，不能同时保留两条。
- 删除场景页时级联删除该页的所有映射，并把剩余场景页重新连续编号。
- 删除素材页、移除小场景素材关联时，级联删除受影响的映射。
- 不写入演示数据或默认业务数据。

## 5. 数据库设计

沿用 `DatabaseManager` 当前激活的 SQLite 数据库，不新建独立数据库。

### 5.1 `small_scenes`

```sql
CREATE TABLE IF NOT EXISTS small_scenes (
    id TEXT PRIMARY KEY,
    large_scene_id TEXT NOT NULL,
    name TEXT NOT NULL,
    scene_type TEXT NOT NULL DEFAULT 'content',
    description TEXT NOT NULL DEFAULT '',
    sort_order INTEGER NOT NULL,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    FOREIGN KEY (large_scene_id)
        REFERENCES large_scenes(id) ON DELETE CASCADE,
    UNIQUE (large_scene_id, name),
    CHECK (
        scene_type IN ('content', 'transition')
    )
);

CREATE INDEX IF NOT EXISTS idx_small_scenes_large_scene_sort
    ON small_scenes(large_scene_id, sort_order);
```

规则：

- `scene_type`：`content`（内容段）或 `transition`（过渡段），默认 `content`。
- `sort_order`：每个大场景内从 1 开始连续排列。
- 同一大场景内名称忽略大小写唯一（`COLLATE NOCASE` 通过 UNIQUE 约束实现）。
- 删除大场景时级联删除所有小场景。

### 5.2 `shot_pages`

```sql
CREATE TABLE IF NOT EXISTS shot_pages (
    id TEXT PRIMARY KEY,
    small_scene_id TEXT NOT NULL,
    branch_id TEXT,
    title TEXT NOT NULL,
    description TEXT NOT NULL DEFAULT '',
    prompt_text TEXT NOT NULL DEFAULT '',
    negative_prompt TEXT NOT NULL DEFAULT '',
    sort_order INTEGER NOT NULL,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    FOREIGN KEY (small_scene_id)
        REFERENCES small_scenes(id) ON DELETE CASCADE,
    FOREIGN KEY (branch_id)
        REFERENCES branches(id) ON DELETE CASCADE
);

CREATE INDEX IF NOT EXISTS idx_shot_pages_small_scene_sort
    ON shot_pages(small_scene_id, sort_order);

CREATE INDEX IF NOT EXISTS idx_shot_pages_branch_sort
    ON shot_pages(branch_id, sort_order);
```

规则：

- `branch_id` 为 NULL 时表示主线分镜页，非 NULL 时表示分支覆盖页面。
- `title`：必填，1–120 字，去除首尾空白。
- `description`：最多 500 字。
- `prompt_text`：最多 50,000 字。
- `negative_prompt`：最多 20,000 字。
- 同一小场景主线内标题唯一；同一分支内标题唯一。
- 删除小场景时级联删除所有主线分镜页。
- 删除分支时级联删除该分支下所有分镜页。

### 5.3 `branches`

```sql
CREATE TABLE IF NOT EXISTS branches (
    id TEXT PRIMARY KEY,
    parent_type TEXT NOT NULL,
    parent_id TEXT NOT NULL,
    name TEXT NOT NULL,
    description TEXT NOT NULL DEFAULT '',
    is_enabled INTEGER NOT NULL DEFAULT 1,
    sort_order INTEGER NOT NULL,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    CHECK (
        parent_type IN ('large_scene', 'small_scene')
    )
);

CREATE INDEX IF NOT EXISTS idx_branches_parent
    ON branches(parent_type, parent_id, sort_order);
```

规则：

- `parent_type`：`large_scene` 或 `small_scene`，表示分支挂载的父级。
- `parent_id`：对应 `large_scenes.id` 或 `small_scenes.id`。
- `is_enabled`：1 表示启用，0 表示停用。
- 同一父级内名称唯一。
- 删除大场景时，应用层负责删除其下所有分支（大场景级和小场景级）。
- 删除小场景时，应用层负责删除其下所有分支。

### 5.4 `small_scene_materials`

```sql
CREATE TABLE IF NOT EXISTS small_scene_materials (
    id TEXT PRIMARY KEY,
    small_scene_id TEXT NOT NULL,
    material_id TEXT NOT NULL,
    sort_order INTEGER NOT NULL DEFAULT 0,
    created_at TEXT NOT NULL,
    PRIMARY KEY (small_scene_id, material_id),
    FOREIGN KEY (small_scene_id)
        REFERENCES small_scenes(id) ON DELETE CASCADE,
    FOREIGN KEY (material_id)
        REFERENCES materials(id) ON DELETE CASCADE
);

CREATE INDEX IF NOT EXISTS idx_small_scene_materials_material
    ON small_scene_materials(material_id, small_scene_id);
```

规则：

- 同一小场景内同一素材只能关联一次。
- `sort_order` 用于前端展示顺序。
- 删除小场景时级联删除关联。
- 删除素材时级联删除所有引用该素材的关联。

### 5.5 `shot_page_materials`

```sql
CREATE TABLE IF NOT EXISTS shot_page_materials (
```

规则：

- 同一分镜页内同一素材只能关联一次。
- `sort_order` 用于前端展示顺序。
- 删除分镜页时级联删除关联。
- 删除素材时级联删除所有引用该素材的关联。

## 12. 级联删除规则

| 删除操作 | 级联影响 |
|---|---|
| 删除大场景 | 删除其下所有小场景 → 每个小场景的分支、分镜页、素材关联全部删除 |
| 删除小场景 | 删除其下所有分支、分镜页、小场景素材关联 |
| 删除分支 | 删除该分支下所有分镜页 → 每个分镜页的素材关联删除 |
| 删除分镜页 | 删除该分镜页的素材关联 |
| 删除素材 | 删除所有引用该素材的小场景关联和分镜页关联 |

要求：

- 大场景删除的级联通过 SQLite `ON DELETE CASCADE` 自动处理 `small_scenes`，但 `branches` 表的 `parent_id` 是多态外键（不指向单一表），需要应用层在删除大场景/小场景时手动清理对应分支及其下分镜页。
- 分镜页和素材关联的级联通过 `ON DELETE CASCADE` 自动处理。
- 删除后重排剩余同级项目的 `sort_order` 为连续 1..N。

## 14. 性能要求

- 列表 SQL 必须分页或限量。
- 列表查询一次返回关联计数（`shot_page_count`、`branch_count`、`material_ids`），禁止 N+1 查询。
- 素材关联设置使用单事务完成替换。
- 500 条小场景下，首屏列表接口目标小于 300 ms。
- 删除操作必须在单事务内完成级联清理和重排。

## 18. 实际解决方案

### 18.1 数据库

在 `backend/app/database.py` 的 `initialize()` 方法中新增 7 张表：

| 表名 | 说明 |
|---|---|
| `materials` | 全局素材，含 6 种类型、验证状态、预览图 |
| `material_tags` | 素材标签，多对多 |
| `small_scenes` | 小场景，挂在大场景下 |
| `branches` | 条件分支，多态父级（large_scene/small_scene） |
| `shot_pages` | 分镜页，主线或分支归属 |
| `small_scene_materials` | 小场景↔素材关联 |
| `shot_page_materials` | 分镜页↔素材关联 |

迁移方法 `_migrate_v040_tables()` 逐表检测存在性，安全创建不覆盖现有数据。

### 18.2 DatabaseManager 方法

新增 20 个方法：

- 素材：`list_materials`、`get_material`、`create_material`、`update_material`、`delete_material`
- 小场景：`list_small_scenes`、`get_small_scene`、`create_small_scene`、`update_small_scene`、`move_small_scene`、`delete_small_scene`
- 分镜页：`list_shot_pages`、`get_shot_page`、`create_shot_page`、`update_shot_page`、`move_shot_page`、`delete_shot_page`
- 分支：`list_branches`、`get_branch`、`create_branch`、`update_branch`、`delete_branch`
- 素材关联：`list_small_scene_materials`、`set_small_scene_materials`、`list_shot_page_materials`、`set_shot_page_materials`

### 18.3 API 路由

在 `backend/app/app_factory.py` 中新增 26 个 API 端点，版本号从 0.2.1 升级到 0.4.0。

### 18.4 级联删除实现

- `small_scenes`、`shot_pages`、`small_scene_materials`、`shot_page_materials` 使用 SQLite `ON DELETE CASCADE`。
- `branches` 表使用多态外键（`parent_type` + `parent_id`），无法使用 CASCADE，在 `delete_small_scene` 和 `delete_large_scene`（已有）中应用层手动清理。
- `delete_branch` 手动清理分支下分镜页及其素材关联。
- `delete_material` 通过 CASCADE 自动清理所有关联表引用。

### 18.5 修复的已有 Bug

1. `create_small_scene`、`create_shot_page`、`create_branch` 中使用了 `uuid.uuid4()` 而非导入的 `uuid4()`，已修正。
2. `create_shot_page` 中查询 `branches` 表引用了不存在的 `small_scene_id` 列，已修正为 `parent_id`。
