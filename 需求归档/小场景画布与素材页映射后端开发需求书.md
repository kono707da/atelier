# Atelier 小场景画布与素材页映射后端开发需求书

版本：v1.0  
状态：待后端开发  
前端基线：`GPT-MAIN`

## 1. 开发目标

为现有剧本画布补齐以下后端能力：

1. 在大场景下管理小场景。
2. 在小场景下管理场景页：新增、修改、删除、排序。
3. 在素材下管理只读展示用的素材页。
4. 将素材关联到小场景。
5. 将某个素材页映射到一个或多个场景页。
6. 提供项目剧本树和小场景工作区聚合接口，避免前端 N+1 请求。

本期不开发提示词、人物、LoRA、ComfyUI 工作流或 AI 自动编排。

## 2. 已确认业务规则

- 项目层级固定为：项目 → 章节 → 大场景 → 小场景。
- 小场景包含任意数量的场景页。
- 场景页首版只有：
  - 页面名称
  - 画面描述
  - 排序
  - 素材页映射
- 素材页属于素材库中的某一个素材，在小场景画布内只读，不允许编辑。
- 同一个素材页可以同时映射到多个场景页。
- 同一个场景页可以同时绑定不同类型的素材页，例如场景、表情、光线各一页。
- 同一个场景页在同一种素材类型下最多只能绑定一个素材页。
- 新绑定同类型素材页时，必须原子替换旧绑定，不能同时保留两条。
- 删除场景页时级联删除该页的所有映射，并把剩余场景页重新连续编号。
- 删除素材页、移除小场景素材关联时，级联删除受影响的映射。
- 不写入演示数据或默认业务数据。

## 3. 数据库要求

功能数据只写入现有生产数据库。不要新增或恢复产品级测试数据库入口。自动化测试应通过临时目录创建独立 SQLite 文件，不接触用户生产库。

### 3.1 `small_scenes`

| 字段 | 类型 | 约束 |
|---|---|---|
| id | TEXT | 主键，UUID |
| large_scene_id | TEXT | 外键 `large_scenes.id`，级联删除 |
| name | TEXT | 必填，清理连续空白，最长 80 |
| sort_order | INTEGER | 从 1 开始，所属大场景内连续 |
| created_at | TEXT | UTC ISO 8601 |
| updated_at | TEXT | UTC ISO 8601 |

约束与索引：

- `UNIQUE (large_scene_id, name COLLATE NOCASE)`
- `INDEX (large_scene_id, sort_order)`

### 3.2 `small_scene_pages`

| 字段 | 类型 | 约束 |
|---|---|---|
| id | TEXT | 主键，UUID |
| small_scene_id | TEXT | 外键 `small_scenes.id`，级联删除 |
| name | TEXT | 必填，最长 80 |
| description | TEXT | 非空默认空字符串，最长 2000 |
| sort_order | INTEGER | 从 1 开始，所属小场景内连续 |
| created_at | TEXT | UTC ISO 8601 |
| updated_at | TEXT | UTC ISO 8601 |

约束与索引：

- `UNIQUE (small_scene_id, name COLLATE NOCASE)`
- `INDEX (small_scene_id, sort_order)`

### 3.3 `material_pages`

| 字段 | 类型 | 约束 |
|---|---|---|
| id | TEXT | 主键，UUID |
| material_id | TEXT | 外键 `materials.id`，级联删除 |
| name | TEXT | 必填，最长 80 |
| description | TEXT | 非空默认空字符串，最长 2000 |
| sort_order | INTEGER | 从 1 开始，所属素材内连续 |
| created_at | TEXT | UTC ISO 8601 |
| updated_at | TEXT | UTC ISO 8601 |

约束与索引：

- `UNIQUE (material_id, name COLLATE NOCASE)`
- `INDEX (material_id, sort_order)`

素材页的编辑只属于素材库接口；小场景工作区只读取。

### 3.4 `small_scene_resource_links`

| 字段 | 类型 | 约束 |
|---|---|---|
| id | TEXT | 主键，UUID |
| small_scene_id | TEXT | 外键 `small_scenes.id`，级联删除 |
| material_id | TEXT | 外键 `materials.id`，级联删除 |
| created_at | TEXT | UTC ISO 8601 |

约束与索引：

- `UNIQUE (small_scene_id, material_id)`
- `INDEX (small_scene_id)`

### 3.5 `small_scene_page_mappings`

| 字段 | 类型 | 约束 |
|---|---|---|
| id | TEXT | 主键，UUID |
| scene_page_id | TEXT | 外键 `small_scene_pages.id`，级联删除 |
| material_page_id | TEXT | 外键 `material_pages.id`，级联删除 |
| material_type | TEXT | 由服务端从所属素材读取，不接受前端任意写入 |
| created_at | TEXT | UTC ISO 8601 |
| updated_at | TEXT | UTC ISO 8601 |

关键约束：

- `UNIQUE (scene_page_id, material_type)`
- `INDEX (scene_page_id)`
- `INDEX (material_page_id)`
- `material_type` 必须属于现有六种素材类型。
- 写入前验证素材已关联到场景页所属的小场景。
- 写入前验证 `material_page_id` 确实属于该素材。

同类型替换必须在一个事务内完成：删除旧映射并写入新映射，任何一步失败都回滚。

## 4. API 契约

所有响应使用 UTF-8 JSON。找不到返回 404，重复名称或重复关联返回 409，参数错误返回 422。

### 4.1 项目剧本树

`GET /api/projects/{project_id}/story-tree`

响应：

```json
{
  "project_id": "uuid",
  "chapters": [
    {
      "id": "uuid",
      "project_id": "uuid",
      "name": "第一章",
      "sort_order": 1,
      "large_scenes": [
        {
          "id": "uuid",
          "chapter_id": "uuid",
          "name": "公共沙滩区",
          "scene_type": "content",
          "sort_order": 1,
          "small_scenes": [
            {
              "id": "uuid",
              "large_scene_id": "uuid",
              "name": "初到沙滩",
              "sort_order": 1,
              "page_count": 10,
              "resource_count": 3,
              "pages": [
                {"id": "uuid", "name": "到达", "sort_order": 1}
              ],
              "resources": [
                {
                  "link_id": "uuid",
                  "material_id": "uuid",
                  "name": "沙滩场景",
                  "material_type": "scene",
                  "page_count": 4
                }
              ]
            }
          ]
        }
      ]
    }
  ]
}
```

要求：

- 严格按各层 `sort_order` 排序。
- 使用聚合查询或批量查询，禁止按节点逐条查询。
- 树接口只返回目录所需轻量字段，不返回素材正文、提示词或图片二进制。

### 4.2 小场景 CRUD

#### 创建

`POST /api/large-scenes/{large_scene_id}/small-scenes`

```json
{"name": "初到沙滩"}
```

#### 修改

`PATCH /api/small-scenes/{small_scene_id}`

```json
{"name": "更名后的小场景"}
```

#### 删除

`DELETE /api/small-scenes/{small_scene_id}`

删除后重新连续编号同一大场景内的剩余小场景。

### 4.3 小场景工作区

### 4.4 场景页 CRUD 与排序

#### 创建

`POST /api/small-scenes/{small_scene_id}/pages`

```json
{
  "name": "到达",
  "description": "人物站在沙滩入口"
}
```

#### 修改

`PATCH /api/small-scene-pages/{page_id}`

```json
{
  "name": "到达沙滩",
  "description": "修改后的画面描述"
}
```

支持只提交一个字段，但至少提交一个字段。

#### 删除

`DELETE /api/small-scene-pages/{page_id}`

级联删除映射并连续编号。

#### 排序

`PUT /api/small-scenes/{small_scene_id}/pages/order`

```json
{
  "page_ids": ["page-2", "page-1", "page-3"]
}
```

要求：

- 必须完整包含该小场景当前全部页面 ID。
- 不允许重复、遗漏或混入其他小场景页面。
- 在单事务内更新为 1..N。

### 4.5 素材页 CRUD 与排序

供素材库后续页面使用，小场景画布不直接调用编辑接口。

- `GET /api/materials/{material_id}/pages`
- `POST /api/materials/{material_id}/pages`
- `PATCH /api/material-pages/{page_id}`
- `DELETE /api/material-pages/{page_id}`
- `PUT /api/materials/{material_id}/pages/order`

字段与场景页相同：`name`、`description`、`sort_order`。

### 4.6 小场景关联素材

#### 关联

`POST /api/small-scenes/{small_scene_id}/resources`

```json
{"material_id": "uuid"}
```

响应至少包含创建后的关联记录。

#### 移除

`DELETE /api/small-scene-resource-links/{link_id}`

移除关联时级联删除当前小场景中指向该素材所有素材页的映射，但不得删除素材或素材页本身。

### 4.7 设置或取消素材页映射

`PUT /api/small-scene-pages/{scene_page_id}/mappings/{material_type}`

设置或替换：

```json
{"material_page_id": "uuid"}
```

取消该类型映射：

```json
{"material_page_id": null}
```

要求：

1. URL 中 `material_type` 必须与素材页所属素材类型一致。
2. 素材必须已关联到场景页所属小场景。
3. 设置新值时原子替换该场景页同类型旧映射。
4. 不影响该场景页其他素材类型的映射。
5. 不影响其他场景页，可让多个场景页指向同一素材页。

## 5. 数据一致性

- 所有删除、排序、映射替换必须使用事务。
- 启用 `PRAGMA foreign_keys = ON`。
- 所有列表稳定按 `sort_order, created_at` 排序。
- 删除或移动后不得留下 `sort_order` 空洞。
- 生产库升级使用幂等迁移：已有表、列和索引时不得报错或丢数据。
- 数据库操作不得在请求循环内反复开连接。

## 6. 性能要求

- `story-tree` 在正常项目规模下最多使用固定数量的批量查询，不随节点数量线性增加查询次数。
- `workspace` 一次返回当前小场景所需的全部轻量数据。
- 素材正文和原图不得进入上述两个聚合响应。
- 素材列表继续使用现有分页和缩略图机制，不能因新增素材页破坏百万图片级懒加载设计。
- 必须为所有外键和排序字段建立索引。

## 7. 安全与校验

- 所有 ID 使用参数绑定，不拼接 SQL。
- 名称清理首尾空白与连续空白。
- 服务端计算 `material_type`，不信任请求体。
- 校验跨项目、跨小场景、未关联素材和不存在资源。
- 删除图片或文件时沿用现有安全路径校验，不允许路径穿越。

## 8. 自动化测试

至少覆盖：

1. 小场景新增、改名、删除、同名冲突和连续排序。
2. 场景页新增、修改、删除、完整重排和非法重排。
3. 素材页 CRUD、排序和素材删除级联。
4. 小场景关联与移除素材。
5. 一个素材页映射到多个场景页。
6. 一个场景页同时绑定场景、表情、光线各一页。
7. 同场景页第二次绑定表情页时替换旧表情映射。
8. 替换表情映射时保留场景和光线映射。
9. 未关联素材、跨小场景页面、类型不匹配必须拒绝。
10. 删除场景页、素材页、素材关联后无孤儿映射。
11. `story-tree` 和 `workspace` 响应结构、排序和空状态。
12. 测试只使用临时 SQLite 文件，不读写用户生产库。

## 9. 后端完成后的验收标准

- 当前前端不再显示“小场景后端待开发”。
- 项目画布能真实显示小场景、页数和关联素材数。
- 双击小场景能进入工作区。
- 场景页新增、编辑、删除、前移、后移刷新后结果不丢失。
- 关联素材后显示其只读素材页。
- 点击素材页后的 P 编号能绑定、替换或取消映射。
- 同类型唯一规则由数据库和 API 双重保证。
- 浏览器控制台无错误，全部后端测试通过。
