## 4. 唯一业务规则

素材页映射的目标页面必须同时满足：

1. 页面存在于 `shot_pages`。
2. 页面拥有有效的 `small_scene_id`。
3. 页面 `branch_id IS NULL`。
4. 页面是小场景直属场景页。

以下页面不得作为映射目标：

- 分支页面。
- 不存在的页面。
- 只有 `branch_id`、没有有效直属关系的异常页面。

该规则同时适用于：

- 新建映射。
- 替换映射。
- 使用 `PUT + null` 取消映射。

## 5. 后端实现要求

目标方法：

```python
DatabaseManager.set_small_scene_page_mapping(
    scene_page_id,
    material_type,
    material_page_id,
)
```

### 5.1 固定校验顺序

必须按照下面顺序处理：

1. 校验 `material_type` 是否有效。
2. 打开数据库事务。
3. 查询目标场景页：

```sql
SELECT id, small_scene_id, branch_id
FROM shot_pages
WHERE id = ?
```

4. 查询不到页面时，抛出“场景页不存在”。
5. `branch_id IS NOT NULL` 时，抛出“分支页面不能设置素材页映射”。
6. 只有目标页面校验通过后，才允许处理 `material_page_id`。
7. `material_page_id IS NULL` 时，删除当前页面和类型的映射并返回 `None`。
8. `material_page_id` 非空时，继续执行素材页、素材类型和小场景关联校验。
9. 设置或替换映射。

禁止在场景页查询前执行：

```python
if material_page_id is None:
    ...
    return None
```

### 5.2 事务要求

- 页面校验和映射修改必须使用同一个数据库连接。
- 取消映射不得先建立一个独立事务再返回。
- 任意校验失败时不得修改映射表。
- 不得产生部分提交。

### 5.3 正常页面取消映射

直属页面存在时：

```http
PUT /api/small-scene-pages/{scene_page_id}/mappings/{material_type}
```

请求：

```json
{
  "material_page_id": null
}
```

无论原映射是否存在，都允许幂等成功：

```http
200 OK
```

```json
{
  "database_environment": "production",
  "mapping": null
}
```

### 5.4 不存在页面

页面不存在时，无论请求是设置还是取消，都必须返回：

```http
404 Not Found
```

```json
{
  "detail": "场景页不存在"
}
```

### 5.5 分支页面

目标是分支页面时，无论请求是设置还是取消，都必须返回：

```http
422 Unprocessable Entity
```

```json
{
  "detail": "分支页面不能设置素材页映射"
}
```

不得因为分支页面同时保存了 `small_scene_id` 就接受映射。

## 6. 路由错误码要求

接口：

```http
PUT /api/small-scene-pages/{scene_page_id}/mappings/{material_type}
```

路由层必须保持以下映射：

| 情况 | HTTP 状态码 |
|---|---:|
| 正常设置映射 | 200 |
| 正常替换映射 | 200 |
| 正常取消映射 | 200 |
| 正常页面重复取消 | 200 |
| 场景页不存在 | 404 |
| 素材页不存在 | 404 |
| 素材不存在 | 404 |
| 分支页面作为目标 | 422 |
| 素材类型不一致 | 422 |
| 素材未关联到小场景 | 422 |
| 非法 `material_type` | 422 |

现有路由已经根据异常文本区分 `404` 和 `422`。如果数据库层使用新的异常类型，应同步调整路由，但不得改变上述结果。
