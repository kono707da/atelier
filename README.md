# Atelier

Atelier 是一套面向 ComfyUI 的项目化视觉生产工作台。

当前已按《Atelier 全功能产品与技术开发需求》逐阶段实现核心业务闭环。包含可运行的 FastAPI
底座、SQLite 生产数据库、版本化迁移框架，项目管理、素材库、人物库、剧本结构等
第一阶段功能，ComfyUI 工作流系统（连接层/工作流库/节点编辑器/规整布局/语义插槽/转换发布）等第二阶段功能，
以及编译、批量生成与任务中心（页级编译器/批次快照/持久化任务队列/ComfyUI 提交/实时进度/故障恢复/输出图片实例/任务中心 API）等第三阶段后端功能。

## 当前可用功能

- FastAPI 单端口应用服务（默认 8110）
- SQLite WAL 生产数据库：`data/atelier.db`
- 版本化数据库迁移框架（`schema_migrations` 表追踪迁移版本，幂等执行）
- 核心编辑表乐观并发控制（`revision` 字段）
- 统一错误响应格式与 Request ID 追踪（响应头 `X-Request-ID`）
- 项目管理闭环：项目 CRUD、同名支持、搜索/筛选/排序/分页、归档/恢复、软删除/回收站/永久删除、项目复制、概览统计、封面上传
- 素材库闭环：素材归档/恢复/软删除/回收站/永久删除、引用反查、素材页预览图/复制、版本历史、素材复制
- 人物库闭环：人物/变体/规格的 CRUD、归档/恢复/软删除/永久删除、标签管理、预览图上传、复制、引用反查、规格矩阵管理、场景页人物绑定
- 剧本结构补全：分支条件字段、分支覆盖数据（人物/素材/参数，支持页面级优先）、剧本快照和版本、操作历史与撤销重做、页面级继承来源展示、编译预检查
- 章节和大场景的创建/改名/删除、跨章节移动
- 小场景工作区：场景页 CRUD、素材关联、素材页映射（同类型原子替换）
- ComfyUI 连接层：HTTP 客户端（连接池/超时/错误处理）、节点定义同步与缓存、模型资源同步、连接测试
- 工作流库：工作流 CRUD、UI JSON/API JSON/图片元数据导入、版本发布、草稿管理、归档/恢复/复制、全局/项目默认工作流
- 通用节点编辑器：节点/连线 CRUD、端口类型校验、未知节点只读保留、复制/删除/禁用/旁路/折叠/多选、工作流校验
- 规整布局：稳定拓扑分层、结构化调整（同层/跨层移动）、分组泳道、连线合束、聚焦上/下游/错误节点、500 节点性能支持
- 语义插槽：13 个内置插槽、自定义插槽、转换规则模板、4 种冲突策略、插槽解析预览、必填校验
- 工作流转换与发布：规范化结构↔API JSON/UI JSON 转换、导出、发布前预检查（节点定义/必填输入/模型资源/连线/插槽）、基于草稿发布不可变版本、往返测试
- 页级编译器：配置继承优先级（项目→章节→大场景→小场景→分支→页面）、确定性编译（相同输入产生相同 sort_key 和 input_hash）、阻塞错误和警告收集、六类素材页映射解析、工作流版本固定、语义插槽解析
- 跑图列表和批量配置：草稿管理、范围选择（项目/章节/场景/分支/页面）、批量覆盖（实例数/工作流/尺寸/种子策略）、阻塞错误和警告预览、不可变批次快照提交
- 持久化任务队列：批次/任务/attempt/事件/租约表、原子领取、并发限制、失败重试不覆盖旧记录、暂停/继续/取消、应用重启恢复
- ComfyUI 提交：API JSON 构建、/prompt 提交、幂等性保护、超时处理、历史查询
- 实时进度与故障恢复：ComfyUI WebSocket 监听、ProgressTracker 内存索引、SSE 推送前端、WebSocket 断开重连、history 轮询兜底、重启后核对 ComfyUI 队列和未终结任务
- 输出和图片实例：解析所有输出节点和图片、流式下载到临时文件、校验后原子移动、files/image_instances/thumbnails/background_jobs 表、缩略图后台任务基础
- 任务中心 API：跨批次任务列表（状态/项目/批次/错误/时间多维筛选）、任务统计摘要、错误详情和关联对象跳转
- 英文 BAT 启动脚本，启动前自动检查端口归属

## 启动

首次使用：

```bat
setup.bat
```

正式应用：

```bat
start.bat
```

访问 `http://127.0.0.1:8110`。

开发测试应用：

```bat
start-test.bat
```

## 数据库安全规则

- 用户界面只连接生产数据库，不展示数据库环境名称，不提供环境切换按钮。
- 自动化测试使用临时隔离数据目录，绝不能写入生产数据库。
- 数据库 schema 变更通过版本化迁移框架安全升级，支持 PRAGMA 检查和 ALTER TABLE 操作。

## 版本控制分支策略

本仓库区分不同 AI 协作者的产出，分支命名格式为 `dev-YYMMDD-<作者>-<简述>`：

- `dev-260727-chatgpt-baseline`：ChatGPT 协作开发的基线版本，包含 FastAPI 底座、项目/章节/大场景的基础后端与前端预览。
- `dev-260729-GLM5.2-*`：GLM 接管后的开发分支，按全功能需求文档逐阶段实现核心业务闭环。

`main` 分支保存已通过验收的稳定基线；`GLM-MAIN` 分支为测试分支，开发分支合并至 `GLM-MAIN` 供用户测试通过后再合并到 `main`。
